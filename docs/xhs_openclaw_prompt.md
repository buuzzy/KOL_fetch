# 小红书港澳财经 KOL 发现任务

## 背景

我需要在小红书上搜索港澳财经相关内容，找到符合条件的 KOL（博主），输出结构化清单。小红书是 JS 渲染的页面，必须使用 browser 工具操作，不要用 web_fetch。

## 前提

- 我已开启 Browser Relay 并附加到 Chrome 标签页
- 当前标签页已打开小红书（xiaohongshu.com）

---

## 搜索关键词

按以下顺序逐个搜索，每个关键词完成后再搜下一个：

1. 港股
2. 美股
3. 港股分析
4. 香港投資

如果时间充裕，可继续搜索：

5. 恒指
6. 港股ETF
7. 香港理財
8. 港股美股

---

## 操作步骤

### 第一步：搜索关键词

1. 用 `browser.navigate` 打开：`https://www.xiaohongshu.com/search_result?keyword={关键词}`
2. 等待页面加载完成
3. 用 `browser.snapshot` 获取页面快照，确认搜索结果已渲染

### 第二步：浏览搜索结果

1. 在搜索结果页，用 `browser.snapshot` 读取当前可见的帖子列表
2. 每条帖子在搜索结果页通常显示：
   - 帖子封面/标题
   - 发帖人昵称
   - 点赞数（❤️ 图标旁的数字）
3. 记录点赞数 ≥ 600 的帖子，准备点进去查看详情
4. 用 `browser.act` 向下滚动 2-3 屏，获取更多结果
5. 每次滚动后用 `browser.snapshot` 重新读取新内容
6. 每个关键词收集 5-10 条符合条件的帖子即可，不用穷尽

### 第三步：进入帖子详情页

对每条筛选出的帖子：

1. 用 `browser.act` 点击该帖子（使用 snapshot 中的 ref ID）
2. 等待详情页加载，用 `browser.snapshot` 读取以下信息：

| 需记录的字段 | 在页面中的位置 |
|------------|--------------|
| 帖子标题 | 详情页顶部或正文第一行 |
| 帖子概要 | 正文前 100 字 |
| 点赞数 | ❤️ 图标旁 |
| 收藏数 | ⭐ 图标旁 |
| 评论数 | 💬 图标旁 |
| 发帖人昵称 | 头像旁的用户名 |
| 帖子链接 | 当前页面 URL，格式 `https://www.xiaohongshu.com/explore/{note_id}` |

3. 计算总互动 = 点赞 + 收藏 + 评论，如果总互动 < 600 则跳过该帖子

### 第四步：进入发帖人主页

1. 在帖子详情页，用 `browser.act` 点击发帖人头像或昵称
2. 等待主页加载，用 `browser.snapshot` 读取：

| 需记录的字段 | 在页面中的位置 |
|------------|--------------|
| 昵称 | 主页顶部大字 |
| 小红书号 | 昵称下方，"小红书号：xxxxxxxx" |
| 粉丝数 | 统计区域，"关注 / 粉丝 / 获赞与收藏" 中间的数字 |
| 简介 | 昵称下方的 Bio 文本 |
| IP 属地 | 如有显示，如 "IP属地：香港" |
| 主页链接 | 当前页面 URL，格式 `https://www.xiaohongshu.com/user/profile/{user_id}` |

### 第五步：判断是否入选

**必须全部满足：**
- 粉丝数 ≥ 1,000
- 粉丝数 ≤ 200,000
- 内容与财经/投资相关（从简介和帖子内容判断）
- 不是新闻媒体（排除：彭博、信报、经济日报、南华早报、香港01 等）
- 不是机构官方号（排除：富途、老虎证券、汇丰、中银等）

**符合条件 → 记录到结果表**
**不符合 → 跳过，返回搜索结果页继续下一条**

### 第六步：返回继续

1. 用 `browser.navigate` 返回搜索结果页，或用浏览器后退
2. 继续处理下一条帖子
3. 当前关键词处理完后，进入下一个关键词

---

## 去重规则

- 如果同一个博主已经被记录过（小红书号或主页链接相同），不重复记录
- 但在"发现关键词"列中追加新关键词

---

## 操作节奏

- 每次 `browser.act` 操作后等待 2-3 秒再做 `browser.snapshot`，确保页面加载完成
- 如果遇到验证码弹窗或登录提示，用 `browser.screenshot` 截图告诉我，暂停等我处理
- 如果某个页面加载异常，跳过该条，继续下一条

---

## 最终输出

完成所有关键词搜索后，将结果整理为以下 Markdown 表格：

```
| 序号 | 博主昵称 | 小红书号 | 粉丝数 | IP属地 | 内容方向 | 博主主页链接 | 代表帖子标题 | 帖子互动(赞/藏/评) | 帖子链接 | 发现关键词 |
```

**各列说明：**

- 序号：从 1 开始递增
- 博主昵称：小红书显示名称
- 小红书号：用户唯一标识，如 "12345678"
- 粉丝数：主页显示的粉丝数
- IP属地：页面有则填，无则填"未知"
- 内容方向：根据简介和帖子判断，如"港股分析"、"ETF投资"、"理财教学"
- 博主主页链接：完整 URL
- 代表帖子标题：触发发现的那条帖子的标题
- 帖子互动(赞/藏/评)：格式 "1200/350/89"
- 帖子链接：完整 URL
- 发现关键词：通过哪个关键词搜到的，多个用逗号分隔

## 最终目标

每个关键词找到 5-10 个符合条件的博主，去重后预期产出 20-40 个港澳财经 KOL。宁可少记也要确保数据准确，特别是粉丝数和链接。
